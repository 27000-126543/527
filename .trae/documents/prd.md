## 1. 产品概述

大型跨境电商平台的全球卖家管理、商品质量抽检与知识产权保护系统，面向跨境电商平台运营场景，解决卖家资质审核、商品侵权检测、质量抽检、知识产权投诉与申诉、保证金退还等核心业务问题。目标用户为平台卖家、审核员、质检机构、知识产权权利人和财务人员，旨在通过自动化流程与多角色协同，提升平台治理效率、降低侵权风险、保障消费者权益。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 卖家 | 企业注册，提交资质 | 商品上架/管理、申诉、保证金退还申请、查看通知 |
| 平台审核员 | 平台内部分配 | 资质审核、侵权复审、申诉仲裁、通知管理 |
| 质检机构 | 平台邀请注册 | 接收抽检任务、上传检测报告、查看抽检历史 |
| 知识产权权利人 | 自主注册 | 上传权利证明、发起投诉、确认侵权清单、查看投诉进展 |
| 财务 | 平台内部分配 | 审批保证金退还、查看运营报表、区域数据统计 |

### 2.2 功能模块

1. **统一登录页**: 角色选择、登录表单、注册入口
2. **卖家工作台**: 资质提交、信誉评分、商品管理（上架/锁定/下架）、申诉中心、保证金管理、消息通知
3. **审核员工作台**: 资质审核队列、侵权复审队列、申诉仲裁队列、通知管理
4. **质检机构工作台**: 抽检任务列表、检测报告上传、抽检历史记录
5. **知识产权权利人工作台**: 权利证明管理、投诉发起、侵权商品确认、投诉进展跟踪
6. **财务工作台**: 保证金退还审批、运营对比报表、区域数据仪表盘
7. **消息通知中心**: 实时消息推送、凭证下载、消息分类筛选

## 3. 核心流程

### 3.1 卖家注册与资质审核流程

卖家注册并提交企业资质 → 系统自动对接全球企业数据库校验真实性 → 生成初始信誉评分 → 推送审核员人工复核 → 审核通过后卖家可开始商品上架。

```mermaid
flowchart TD
    "卖家注册" --> "提交企业资质"
    "提交企业资质" --> "系统自动校验(全球企业数据库)"
    "系统自动校验(全球企业数据库)" --> "校验通过?"
    "校验通过?" -->|"是"| "生成初始信誉评分"
    "校验通过?" -->|"否"| "推送审核员人工复核"
    "推送审核员人工复核" --> "审核员判定"
    "审核员判定" -->|"通过"| "生成初始信誉评分"
    "审核员判定" -->|"驳回"| "通知卖家补充材料"
    "通知卖家补充材料" --> "提交企业资质"
    "生成初始信誉评分" --> "卖家激活"
```

### 3.2 商品上架与侵权检测流程

卖家提交商品信息 → 系统自动检测标题/描述/图片是否命中侵权商品库 → 未命中则正常上架 → 命中则自动锁定并推送审核员复审 → 审核员判定通过/下架。

```mermaid
flowchart TD
    "卖家提交商品" --> "系统自动侵权检测(标题/描述/图片)"
    "系统自动侵权检测(标题/描述/图片)" --> "命中侵权库?"
    "命中侵权库?" -->|"否"| "商品正常上架"
    "命中侵权库?" -->|"是"| "商品自动锁定"
    "商品自动锁定" --> "推送审核员复审"
    "推送审核员复审" --> "审核员判定"
    "审核员判定" -->|"通过"| "商品正常上架"
    "审核员判定" -->|"下架"| "商品强制下架"
    "商品强制下架" --> "扣减卖家信誉分"
```

### 3.3 质量抽检流程

系统根据商品类目和历史投诉率自动生成抽检计划 → 指派就近质检机构 → 质检机构上门采样并上传检测报告 → 系统根据结果更新商品状态 → 不合格则强制下架并扣减信誉分。

```mermaid
flowchart TD
    "系统生成抽检计划" --> "指派就近质检机构"
    "指派就近质检机构" --> "质检机构上门采样"
    "质检机构上门采样" --> "上传检测报告"
    "上传检测报告" --> "系统判定结果"
    "系统判定结果" -->|"合格"| "商品状态: 正常"
    "系统判定结果" -->|"预警"| "商品状态: 预警"
    "系统判定结果" -->|"不合格"| "商品强制下架"
    "商品强制下架" --> "扣减卖家信誉分"
```

### 3.4 知识产权投诉与申诉流程

权利人上传权利证明发起投诉 → 系统自动匹配疑似侵权商品 → 权利人确认 → 系统生成下架通知推送卖家 → 卖家可申诉提交反证 → 系统重新比对 → 推送审核员仲裁。

```mermaid
flowchart TD
    "权利人上传权利证明" --> "发起投诉"
    "发起投诉" --> "系统自动匹配疑似侵权商品"
    "系统自动匹配疑似侵权商品" --> "权利人确认侵权清单"
    "权利人确认侵权清单" --> "系统生成下架通知"
    "系统生成下架通知" --> "推送给卖家"
    "推送给卖家" --> "卖家申诉?"
    "卖家申诉?" -->|"否"| "商品下架生效"
    "卖家申诉?" -->|"是"| "卖家提交反证"
    "卖家提交反证" --> "系统重新比对"
    "系统重新比对" --> "推送审核员仲裁"
    "推送审核员仲裁" --> "审核员判定"
    "审核员判定" -->|"申诉成立"| "恢复商品"
    "审核员判定" -->|"申诉驳回"| "商品下架生效"
```

### 3.5 保证金退还流程

卖家发起退还申请 → 系统根据活跃度/投诉率/退货率计算可退比例 → 生成审批单 → 财务审批 → 审批通过自动打款。

```mermaid

    "卖家发起退还申请" --> "系统计算可退比例"
    "系统计算可退比例" --> "生成审批单"
    "生成审批单" --> "财务审批"
    "财务审批" -->|"通过"| "自动打款"
    "财务审批" -->|"驳回"| "通知卖家"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深海蓝 (#0F2B46) 为基础色，搭配翡翠绿 (#10B981) 作为状态正向指标，琥珀橙 (#F59E0B) 作为预警色，珊瑚红 (#EF4444) 作为危险/下架色
- **辅助色**: 石板灰 (#64748B) 用于次要文字，浅灰蓝 (#F1F5F9) 用于背景
- **按钮风格**: 圆角8px，主要操作使用填充按钮，次要操作使用边框按钮，危险操作使用红色填充
- **字体**: 标题使用 DM Sans (Bold/Semibold)，正文使用 Noto Sans SC (Regular/Medium)，数据数字使用 JetBrains Mono
- **布局风格**: 左侧导航栏 + 顶部标题栏 + 内容区卡片式布局，桌面端优先
- **图标风格**: 使用 Lucide 图标库，线性风格，2px 描边
- **数据可视化**: 使用 Recharts 库，配色与主色系一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 统一登录页 | 角色选择 | 五个角色卡片网格布局，hover 放大效果，选中态边框高亮 |
| 统一登录页 | 登录表单 | 居中卡片式表单，输入框带图标前缀，渐变登录按钮 |
| 卖家工作台 | 仪表盘概览 | 四宫格统计卡片(信誉分/商品数/待处理/通知)，最近商品列表，通知时间线 |
| 卖家工作台 | 商品管理 | 表格列表带状态标签(绿/黄/红/灰)，搜索筛选栏，批量操作按钮 |
| 卖家工作台 | 保证金管理 | 环形图显示余额/已退/冻结，退还进度条，申请表单弹窗 |
| 审核员工作台 | 审核队列 | 左侧列表+右侧详情双栏布局，审核操作按钮组，比对高亮 |
| 质检机构工作台 | 抽检任务 | 任务卡片列表带优先级标签，地图式区域分配，报告上传表单 |
| 知识产权权利人工作台 | 投诉发起 | 步骤条引导(选择权利→匹配结果→确认投诉)，侵权商品缩略图网格 |
| 财务工作台 | 运营报表 | 区域对比柱状图、趋势折线图、数据表格，月度切换选择器 |
| 消息通知中心 | 通知列表 | 左侧分类导航+右侧通知流，未读圆点标记，附件下载按钮 |

### 4.3 响应式设计

- 桌面端优先设计，最小宽度 1280px
- 平板端（768px-1279px）侧边栏收起为图标模式
- 移动端（<768px）侧边栏变为底部标签栏，表格转为卡片列表

### 4.4 动效设计

- 页面切换：淡入淡出 + 微滑移
- 状态变更：颜色渐变过渡
- 通知弹出：右上角滑入动画
- 数据更新：数字滚动动画
- 卡片悬停：微上浮 + 阴影加深
